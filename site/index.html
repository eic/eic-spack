EIC Spack repository

Spack packages for the Electron-Ion Collider software stack, building on the Key4hep packages and upstream Spack.

Quick start

git clone https://github.com/eic/eic-spack.git
spack repo add eic-spack/spack_repo/eic
spack install epic

Or build the full environment:

spack env create eic eic-spack/environments/eic/spack.yaml
spack -e eic concretize
spack -e eic install
